# 고정 기체의 사전 비교 결과

배포 폴더: [run_20260924T161648152853Z](baseline_v2/run_20260924T161648152853Z/)

이 폴더만 기존 연구 작업본에서 가져왔다. 다른 기체 후보의 결과는 포함하지 않는다.

- [SUMMARY.md](baseline_v2/run_20260924T161648152853Z/SUMMARY.md): 기체 설정, 61개 시험의 오차·포화·실패·추진 범위 이탈
- [DIAGNOSTICS.md](baseline_v2/run_20260924T161648152853Z/DIAGNOSTICS.md): 트림, 통합 미션의 구간별 지표, 범위 이탈 원인 구분
- `report.json`: 전체 파라미터, LQR 설계, 시험 설정, 원래 실행의 소스 해시, 전체 결과
- `<제어기>_<속도>_<조건>.json`: 개별 지표와 최적화 상태
- 같은 이름의 `.npz`: 시계열 `t`, `x`, `u`, `v_ref`, `z_ref`, `wind`
- `.png`: 대표 응답 / 통합 미션 그래프

NPZ의 `x`와 기준값은 상태 시각에 정렬되며 길이가 N+1이다. `u`, `wind`는 구간 시작 입력이며 길이가 N이다. `x`의 17상태 순서와 단위는 [이식 가이드](../docs/INTEGRATION.md)를 따른다. 중단된 시험은 N과 종료 시간이 더 작다.

`completed`는 중단 조건 없이 계산을 마쳤다는 뜻이며, `tracking_pass`는 정한 말단 오차·포화 기준까지 충족했다는 뜻이다. 추진 모델의 가정 범위는 별도 항목이다. 셋을 같은 의미로 해석하지 않는다.

중단 결과의 RMSE를 완주 결과와 그대로 비교하지 않는다. 새 시험은 새 `run_시각` 폴더에 저장한다. 원래 기록의 메타데이터와 현재 공유본의 차이는 [PROVENANCE.md](../docs/PROVENANCE.md)에 설명했다.
